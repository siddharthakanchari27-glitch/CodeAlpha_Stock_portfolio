# CodeAlpha_Stock_portfolio
Stock portfolio tracker
CodeAlpha Stock Portfolio Tracker

Project Description

The Stock Portfolio Tracker is a simple Python application that calculates the total investment value of a user's stock portfolio using predefined stock prices and user-entered quantities.

Features

- Displays available stocks and their prices.
- Accepts stock names and quantities from the user.
- Calculates the investment value of each stock.
- Displays the total portfolio value.
- Saves the results to a text file.

Technologies Used

- Python
- Dictionaries
- Loops and conditional statements
- User input and output
- File handling

How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project in VS Code.
4. Run "python stock_portfolio.py".

Disclaimer

The stock prices are predefined sample values for educational purposes and are not live market prices.
